Part 1: Sampling Loops

1.1: Implementing the Forward Process

A key part of diffusion is the forward process, which takes a clean image and adds noise to it. Tis process is defined by the following process: given a clean image, we produce a noisy image at timestep t by sampling from a Gaussian with mean and variance based on the noise coefficient and the clean image. Greater time steps result in noisier images, as shown below, comparing the original to times 250, 500, and 750.

1.3: One-Step Denoising

Instead, let's try using a pretrained diffusion model to denoise. We can use it to recover/estimate Gaussian noise from the image, which we can then remove. Here is, again, the original image, the noisy images, and finally the one-step denoised estimates of the original image at each time step. These are already much better than the classical technique.

1.4: Iterative Denoising

As the noise increases, the performance of this gets worse. We can fix this by using the diffusion model to denoise iteratively. There's no need to iterte through all 1000 time steps of the model; I use a regular stride of 30. On the ith denoising step, from t, we are trying to get to smaller timestep t', to produce a less noisy image. We finally reach t = 0, which is the clean image. Below I have the image on every 5th loop of denoising, gradually becoming less noisy. I also show the original compared to the iteratively denoised final image, the one-step denoised version, and the gaussian blurred version. This definitely emphasizes how much better the iterative version is.

Part 2: Training a Flow Matching Model

Evidently, one-step denoising does not work well to generate images. Instead I need to iteratively denoise the image by training a UNet model to predict the `flow' from our noisy data to clean data. Flow from a noisy image x0 to clean image x1 can be thought of as the velocity of a point x at time t, which can be approximated as x1 - x0 for change in time totalling to 1.

2.1: Adding Time Conditioning to UNet

TO do this, we need to inject t into the previous set up of the model to condition it.

2.2: Training the UNet

To train our now time-consitioned UNet, we pick a random image from the training set, a random timestep, and then add noise to create the point x at time t. Then, we can train the denoiser to predict the flow at this point. I used a batch size of 64, an initial learning rate of 1e-2, and an exponential learning rate decay scheduler.
